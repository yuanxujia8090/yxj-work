# 外部技能（skills-main 1.3.1）

x-rail 调用这些已安装技能，不复制它们。缺少时 self_check 会指出名称。

| 技能 | 何时调用 |
|---|---|
| grilling | Frame 的单向门问题 |
| domain-modeling | Frame 里出现领域词 |
| tdd | Execute 的行为改动。seam 写入 decisions.tsv |
| diagnosing-bugs | bug 单元，先有能变红的命令 |
| research | 只读研究，硬超时 15 分钟 |
| code-review | Review 两轴，另一模型家族 |
| codebase-design | tdd 间接调用，不另装 x-codebase-design |
