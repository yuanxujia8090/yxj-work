# 写给代理的阶段卡

吸收 skills-main `writing-for-agents` 1.3.1。阶段卡只写代理下一步要做的事。

- 步骤放在文件前部。文件内的表是参考。外置文件只给路径，不抄正文。
- 每一步都有可检查的完成判据。判据写成能观察的结果，例如「ledger 里有 VERIFIED」。
- 一句话只留一个事实。同一规则只在一个文件里写全，别处给路径。
- 用正向说法：写「先读 capsule.md」，不堆「不要忘记」。
- 能用 `xr` 或 self_check 检查的，不写成劝告。
- 入口不超过 5 KB，一张阶段卡不超过 6 KB，入口加当前阶段卡不超过 12 KB。
- 依赖别的技能时写「调用 Skill 工具 名称」，不写跨目录相对链接。
