# Review Playbook

1. Read the contract, change set, evidence and unverified items.
2. Review correctness, security boundaries, maintainability, completion-condition coverage and workflow file boundary.
3. Classify findings as must-fix, consider, note or rejected; cite files and evidence.
4. State what was not reviewed.
5. This playbook is read-only. Put the review in `.work-docs/tasks/<task-id>/outputs/` only when requested by the contract.
