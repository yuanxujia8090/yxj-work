# evidence：取证脚本

这里的脚本只用于统计 01 中的数字，不属于 x-rail 的实现代码。

- `mine.py`：逐个会话统计指标，输出 sessions.json。指标包括 provider、错误、压缩、子代理调用、task.py 调用。
- `mine2.py`：在 mine.py 的基础上做分类和汇总。包括错误串分类、是否被自动重试、错误后停住的时长、错误簇、延迟分位数、模型切换。

## 运行方式

先把 sessions.tgz 解压到 `/workspace/xrail/sessions`，然后运行：

```
python3 mine.py
python3 mine2.py
```

两个脚本里写死了取证机上的路径。换一台机器运行时，需要先修改脚本里的路径。

## 口径

见 `../01-问题诊断.md` 文末的"取证口径"。

部分一次性统计没有保存成脚本，例如技能读取量、工具错误总数（638/14,414）、空响应和 length 截断。这些都是用短 Python 片段直接扫描 JSONL 得到的，需要时可以按相同口径重算。
