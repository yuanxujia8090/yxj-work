## 4. 六条目标规则

以下为本批目标规则，已写入现有入口和阶段说明；方案本身不作为日常必读材料。

1. **先定结果。** 先读最小相关材料与调用方，明确目标、允许范围、必要输入和验收，复用已有计划。发现范围、风险或验收变化时，执行者先暂停扩大改动，主会话核对后更新边界与下一动作，保留已有修改和有效证据；直接执行时由主会话承担同一责任。调整按现行授权与契约规则办理。
2. **主动交接。** 调用 x-rail 即授权当前目标范围内默认主动委派；宿主可用、目标与读写范围及验收明确时，默认将完整执行单元交给子代理完成调查、实现和相关测试，不等用户逐次点名。独立且资源隔离的项可并行，有依赖项在前置满足后接力；不可并行或文件共享不是父会话包办理由，共享写由同一子代理承接。x-rail-long 优先使用子代理。短小且主会话已掌握材料、交接成本明显更高时直接完成；紧密耦合的实现由同一位执行者承接。边界不清先整理，不按文件或命令机械拆代理。
3. **隔离写入。** 共享文件、父状态、分支、数据库、缓存和构建目录只有一个写入者；并行写入使用独立副本。新独立工作需要隔离历史时采用宿主实际支持的新上下文，并核对真实模式。原工作续接遵守原运行查询与恢复协议，不以新运行绕过现场；本版不增加固定并发或主动设置子代理总时限。
4. **精简返回。** 执行者返回结果、实际修改位置与版本、后继必要约定、验证命令与结果及证据引用、偏差、未解决风险、下一步和原运行位置。大量原文留在执行侧，引用必须实际可访问，关键失败与限制不能省略。主会话在安全节点接收通知，核对产物后更新原工作项；有可推进工作时及时接力或补位，无独立工作则交还控制权等原生通知。
5. **按缺口核验。** 主会话核对实际产物、范围和当前证据，按异常、接口冲突或覆盖不足展开资料，避免重做整项实现。执行者已完成且仍适用的检查直接复用；接入实际交付工作区后核对相关输入、环境和组合影响，补受影响检查。独立审查解决自动覆盖尚未解决的具体风险，现行中高风险和契约必需审查继续履行，不能凭自报或提交号放行。
6. **达到验收就交付。** 开始前明确观察对象、必要检查与结束条件，集中处理阻止交付的问题。修复后定向复核必修问题及受影响部分，满足全部约定验收即结束；非阻塞建议留后续。不默认叠加多轮全量审查，既有必需最终审查仍须完成。

权限、费用、失败处理、有效进展、原运行恢复和完成门继续引用原权威位置，不在每份说明重复一套。耗时只是调查线索，区分复杂度、有效研究和外部阻塞，不增设分类器、计分或时间阈值。

## 6. 后续增强：有证据后再增加精简摘要

启用前提：真实任务显示完整摘要反复加载大量正常已完成项，并影响恢复或决策；记录输出量、读取原因和耗时，再决定是否实施。当前指定会话未证明此项是主要瓶颈，首批不依赖它。

首版仅考虑拟新增的 `summary --compact`，即只显示重点的任务摘要，当前尚不可作为已有命令使用：

- 默认完整命令和原全局检查保持兼容，汇总正常已完成项，显示当前项、就绪项与全部异常。
- 权限、完整范围、风险、必需审查、阻塞、下一步和证据引用保持可见；严重结构错误沿用报错，检查无法完成时明确限制。
- 只生成视图，不存第二份状态、不替代恢复顺序或完成门；不新增历史解析、跨调用缓存或锁定快照承诺。
- 首版推迟 `--item`，即指定展开单个工作项，以及额外前置展开；真实使用证明必要后再评估。

届时单独明确脚本改动与自动行为反例，核对异常可见、只读、默认兼容和原完成门。摘要字节减少只证明输出变化，不能直接推导总提速。

## 7. 风险、限制与调整依据

| 风险 | 处理 |
| --- | --- |
| 交接成本高于直接执行，或共享改动无法隔离 | 缩小委派范围或交同一位执行者，短小工作直接做 |
| 主会话先完整调查再委派，或接收时重复实现 | 派发前只读划界所需材料，接收按具体问题补读；复杂修复作为完整执行任务交接 |
| 减少核验后漏掉用户路径或集成问题 | 以实际交付输入和风险缺口补验证，保留必需独立审查；不把“静态判断”写成真实运行 |
| 规则更新后模型仍不主动派发 | 观察首次可派发时点与实际动作，定位入口冲突或交接缺失，不先堆同义提醒 |
| 用一项规则验收扩大成整套演练 | 只选择实际变更场景，复用有效证据；方法未验证的批量工作才用第一项试跑 |
| 原文与候选规则混用 | 当前规则以技能和原契约为准，本目录是实施前设计；历史决策与当前取舍明确分开 |
| 改动覆盖用户工作 | 先读当前差异，只改本轮授权位置；回退涉及覆盖、删除或清理时先说明风险并取得明确同意 |

功能与效率分开报告。正常执行先记录用户等待、交接、重复检查和可获取的实际用量；需要承诺具体幅度时再安排获授权的同条件对照。固定模型、网关与宿主限制、全局压缩配置及 0.0.5 暂缓实验继续按原决定处理。
