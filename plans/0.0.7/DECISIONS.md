# 0.0.7 决策与多角色审查记录

> 日期：2026-10-19。
> 状态：三角色只读审查后修订，运行代码待实施；本轮只调整 `plans/0.0.7/`。

**已按推荐选了“保留小批交付与持久证据，用一个恢复检查覆盖所有状态出口”，因为原稿存在恢复卡死、解除入口旁路与重复记录；单纯增加命令参数不能解决这些问题。**

## 第一性原理与奥克姆剃刀的落点

像表单草稿恢复一样，必要结果是有效内容能保存、剩余内容能接着做、同项工作不重复启动。必要约束是输入版本、检查覆盖、独立审查、持久事实、单写入者与授权。满足这些结果时，优先复用原单元状态、事件日志和报告；不新建调度系统、状态枚举或必经阶段。不能以简化为由跳过真实状态闭环。

## 审查发现与处置

三位独立子代理分别审查运行可靠性、证据与审查质量、设计简化。主会话核对了 v3 `xr` 的领取、失败、重开、验证、完成和解除决策门入口，以及旧协调模块和原批次 B 的九个问题。下列均是方案审查结论，不是代码修复或运行测试结果。

| 发现与角色 | 处置 | 对应方案 |
| --- | --- | --- |
| 可靠性：原运行恢复成功后，阻塞状态没有完成出口 | 采纳；增加同一原运行恢复为执行中，再验证完成的路径，禁止经过待派发另起运行 | 第 4.3 节、第 7.1 节 |
| 可靠性、简化：解除决策门可把任意阻塞项放回队列 | 采纳；所有离开阻塞的入口共享检查，决策门只解除自身原因，终态重开也不豁免 | 第 4.1—4.3 节 |
| 可靠性：共读文件冲突已被源码证实，且实际入口不在旧候选计算函数 | 采纳；明确修改 `xr next`，旧 `frontier.compute` 不默认纳入 | 第 3.2、4.1、5 节 |
| 简化：缺报告同时被规定为禁止恢复与允许缺失 | 采纳；缺报告只影响可复用量，确认终止不可续后可重规划，覆盖全部记待审 | 第 4.3、第 7.1 节 |
| 简化：报告与新增命令参数重复承载运行事实 | 采纳；撤回多套必填参数，复用单份记录，确有必要只传一个记录引用；阶段只补增量内容 | 第 3.3、第 4.2 节 |
| 证据：重复调查及故障耗时被写得过于确定 | 采纳；改为重复核查风险与待测归因，不把全部接管耗时视为可消除浪费 | 第 1、2、7.3 节 |
| 证据：文件归属不等于原问题覆盖，首份报告质量标准不足 | 采纳；原九问题映射到责任单元和证据；补“已读文件”拒收及漏项反例 | 第 3.2—3.3、第 7.1 节 |
| 证据：跨仓库同步延后合理，但联合加载的执行结果未定义 | 采纳；说明优先级与适用范围，不能消解则明确暂停受影响派发；内部一致与联合验证分开报告 | 第 3.4、第 5 节 |
| 简化：实施流程与指标不必成为额外运行协议 | 采纳；实施交付收为三项，首版只新增两项观察，其余从既有日志按需计算 | 第 6、第 7.3 节 |

父会话补充：阻塞项可能仍有活跃或状态未知的原运行，不能因此释放冲突写入资源；在统一恢复检查与领取候选中保守保留占用。并发上限和资源隔离继续生效，健康独立只读任务可以继续，不额外建设全局熔断系统。

## 保留与延后

| 选择 | 理由与重新评估条件 |
| --- | --- |
| 以实际安装 v3 为目标，实施前核对版本和未提交修改 | 安装链接与主工作区版本不同；不自动合并、覆盖安装或同步其他工作区 |
| 按功能与可验收问题拆分，不按“少于五项”决定父执行 | 文件数和行数仅提示复核；短小且交接成本更高时仍直接完成 |
| 报告头写一次，阶段更新只补结论与剩余范围 | 保留持续保存，减少重复格式维护；只读不允许落盘时改用宿主消息/小批最终输出 |
| 首次故障阻塞、核对原运行、按真实状态恢复 | 宿主内部重试不重复算任务失败；未知状态保持阻塞；报告缺失不阻断确认终止后的重规划 |
| 复用单份记录，不立即扩展所有参数或旧协调模块 | 只有现有材料无法可靠消费时才增专用字段；旧模块依赖旧契约，不直接假定适配 v3 |
| 消费者项目同步和模型请求根因调查延后 | 本轮只改本目录；联合执行、网关、模型配置及安装变更各按当时授权处理 |
| 首先验证确定性状态反例，再观察真实模型行为 | 替身通过不等于模型服从；真实观察不等于普遍提速，不默认追加付费对照 |
| 每轮记录文件体积；本版入口与相关运行说明不净增长 | 用户明确要求体积作为后续迭代考察项；精确基线见体积记录。代码与测试为必要保障可增长，但分别列差值与职责，不把规则搬目录隐藏增长 |
| 用问题—机制—证据逐项判断是否解决 | 方案第 7.5 节区分可执行状态保障、真实模型行为和效率。首次保存前中断仍可能无报告，请求超时根因不在本版，不能承诺全面解决或固定提速 |

本版保留 PStack 的逐项验收、滚动接收、失败分类、持久状态和恢复目的，通过既有结构做本地适配。详细事实、修改位置和验收见[优化方案](./优化方案.md)。审查原始报告保存在宿主管理的会话产物中；仓库仅保留以上合并结论，不复制整套临时报告。
