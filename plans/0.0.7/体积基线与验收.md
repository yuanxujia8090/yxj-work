6. 体积合格与行为合格同时满足才可接受本次实施。阈值不通过先精简重复说明、回到脚本保障；确有必须保留的例外，记录增加量、必要性和替代代价，交付写明“体积目标未达”，不能宣称达标或无声放宽基线。

这些阈值是本次实施目标，不是所有未来版本永远不能增长。以后每轮保留实施前/后两组测量和上轮基线，说明增长是否带来可验证能力；不能每次增长后重置基线掩盖累计膨胀。

## 4. 如何复测

在待验收工作区运行以下只读统计。输出不修改文件，适用于主分支和 v3；实施时还应检查引用变化，统计脚本不能证明实际加载范围完整。

```bash
python3 - <<'PY'
from pathlib import Path
import subprocess

root = Path.cwd()
skill = root / 'skills/x-rail'
excluded = {'node_modules', '.git', '__pycache__', '.venv', 'dist', 'build'}
files = sorted(p for p in skill.rglob('*')
               if p.is_file() and not (set(p.relative_to(skill).parts) & excluded))
links = [p.relative_to(skill).as_posix() for p in files if p.is_symlink()]
print('版本', subprocess.check_output(['git', 'rev-parse', 'HEAD'], text=True).strip())
print('文件符号链接', links)
md = [p for p in files if p.suffix == '.md']
code = [p for p in files if p.suffix in {'.py', '.ts', '.js', '.mjs', '.sh'} or p.name == 'xr']
for label, group in [('说明文档', md), ('代码含测试', code)]:
    print(label, '文件', len(group), '行', sum(len(p.read_bytes().splitlines()) for p in group),
          '字节', sum(len(p.read_bytes()) for p in group))
for name in ['SKILL.md', 'stages/plan.md', 'stages/execute.md', 'stages/review.md',
             'references/brief-template.md', 'references/failure-modes.md']:
    p = skill / name
    if p.is_file():
        raw = p.read_bytes()
        print(name, '行', len(raw.splitlines()), '字节', len(raw))
group = [p for p in md if p.relative_to(skill).parts[0] in {'stages', 'references'}]
print('全部阶段卡与参考说明字节', sum(len(p.read_bytes()) for p in group))
PY
```

迭代交付记录：工作区与版本、是否有未提交差异、同口径实施前/后字节与差值、新增引用、目标是否达到、行为验证证据。读取负担如需量化，另从实际工具读取日志统计；不能把磁盘大小直接写成上下文节省或任务提速。
