# 决定记录

- 两轮安装：先完整检查三个目标，再统一删除和复制，避免部分更新。
- 有效进展：新增 done_when evidence，或 required 验证从 failed/not_run 变为 passed。
- 无进展阈值：L1/L2 为 20 次工具调用；L3/long 每个子任务为 60 次工具调用或 30 分钟。
- 预算：L1/L2/L3 分别为 30/100/400 次工具调用；L3 另有 8 小时上限。
- 策略指纹固定为“修改文件 + 执行命令 + 错误首行”，写入 `audit/`；恢复不能重复已有指纹。
- 证据新鲜度由 `run_at` 与相关文件 `last_edit_at` 比较；过期证据不能支撑 done。
- 新任务前读取 `.work-docs/index.md`；相同范围的进行中任务续接原 task id。
- L1 只建 `state.md`，其他目录按需创建；L2/L3 保持完整结构。
- 旧 `check-plan.sh` 只作历史参考，不列入 required 验证。
- 本决定文件位于任务目录，不放仓库根目录；工作流文件统一在 `.work-docs/`。
